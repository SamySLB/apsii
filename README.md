# Análise e Projeto de Sistemas II

Exercícios realizados no quarto período da faculdade, ministrados pelo professor **Raul Andrade**, onde foram aprendidos e aplicados conceitos como: uso do **Git** e **GitHub**, criação de repositórios, boas práticas de desenvolvimento, **programação orientada a objetos (POO)**, **refatoramento**, identificação de *code smells* (maus cheiros), princípios **SOLID** e o **princípio de segregação de interfaces**.

**Linguagem:**
- Java

**Frameworks e Ferramentas:**
- Eclipse  
- IntelliJ IDEA

## Instalação e Uso

### Pré-requisitos
- **Git** instalado na máquina  
- Conta no **GitHub**  
- **Java JDK 17** (ou superior) instalado e configurado no PATH  
- **IDE** (Eclipse ou IntelliJ IDEA)  
- **Maven** (caso o projeto utilize gerenciamento de dependências)
